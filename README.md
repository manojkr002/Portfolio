# Manoj Kumar — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- About, skills, education, and portfolio sections
- Sticky sidebar and section navigation
- Interactive project preview modal
- Font Awesome icons and remote project-preview images

## Project structure

```text
manoj-kumar-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── README.md
└── .gitignore
```

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a more realistic local development workflow, use the **Live Server** extension in VS Code.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `manoj-kumar-portfolio`.
2. Upload the files while preserving the folder structure.
3. Open **Settings → Pages**.
4. Under the build/deployment settings, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the deployment URL to appear in the Pages section.

## Before publishing — personalize these details

- Replace the placeholder GitHub URL `YOUR-USERNAME` in `index.html`.
- Replace `YOUR-PROFILE` in the LinkedIn URL with your real profile slug.
- Check your email, phone number, location, college name, and education dates.
- Make sure each skill reflects your current level.
- **Important:** The project cards currently describe sample projects. Edit the descriptions and technologies so they match projects you have actually built. Add working repository/demo links when available.
- The HTML currently loads Font Awesome and preview images from external services, so those elements require an internet connection.
